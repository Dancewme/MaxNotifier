# MaxNotifier

[![GitHub Release](https://img.shields.io/github/v/release/Dancewme/MaxNotifier?style=flat-square&label=Latest%20Release)](https://github.com/Dancewme/MaxNotifier/releases/latest)

Утилита для отслеживания новых сообщений в мессенджере **MAX** и отправки
email-уведомлений. При появлении любого нового сообщения (личного или
группового) программа отправляет письмо с темой **«MAX»** и текстом
**«Проверь MAX, пришло новое сообщение.»**

## Принцип работы

Программа **не использует API MAX**. Вместо этого она отслеживает появление
окон уведомлений десктоп-клиента MAX через **Win32 Event Hook**
(`SetWinEventHook`).

- Отслеживаются события `EVENT_OBJECT_CREATE` и `EVENT_OBJECT_SHOW` —
  создание новых окон и показ скрытых окон
- Фильтрация по процессу: мониторятся только окна, созданные процессом
  десктоп-клиента MAX (например, `Max.exe`)
- Главное окно MAX исключается — отслеживаются только всплывающие окна
  уведомлений о новых сообщениях
- Внутренние виджеты Qt (класс `QEventDispatcherWin32*`) отфильтровываются
- При обнаружении окна уведомления отправляется email-уведомление

### Почему не API?

API MAX — это бот-API. Бот видит только сообщения, отправленные ему напрямую,
или чаты, в которые он добавлен. Личные переписки пользователя с другими
людьми недоступны через API. Мониторинг окон уведомлений десктоп-клиента
позволяет отслеживать **все** входящие сообщения без добавления бота в чаты.

### Защита от спама

Между отправляемыми письмами выдерживается интервал `COOLDOWN_SECONDS`
(по умолчанию 60 секунд). Если за это время приходит несколько сообщений,
отправляется только одно письмо.

## Требования

- **Windows 10/11**
- **Python 3.11+** (для запуска из исходников и сборки)
- Десктоп-клиент MAX, установленный и запущенный
- Для сборки: `pyinstaller` (устанавливается через `requirements.txt`)
- Для работы собранного `MaxNotifier.exe`: **Python не требуется**
- **Оба приложения (MAX и MaxNotifier) должны быть запущены от имени администратора**

## Быстрый старт (готовый exe)

1. Скачайте `MaxNotifier.exe` со [страницы релизов](https://github.com/Dancewme/MaxNotifier/releases/latest)
2. **Запустите `MaxNotifier.exe` от имени администратора** (правый клик → "Запуск от имени администратора") — рядом создастся `config.ini`
3. Откройте `config.ini`, заполните SMTP-настройки
4. **Убедитесь, что десктоп-клиент MAX также запущен от имени администратора** — это необходимо для корректной работы Win32 Event Hook (UIPI)
5. Запустите `MaxNotifier.exe` снова (тоже от имени администратора)

> ⚠️ **Важно:** Если MAX и MaxNotifier запущены с разными привилегиями (один от админа, другой — нет), уведомления не будут отслеживаться. Оба приложения должны работать на одном уровне привилегий.

## Установка и запуск из исходников

```bash
pip install -r requirements.txt
python app.py
```

При первом запуске рядом со скриптом создастся `config.ini` с параметрами
по умолчанию. Заполните его и запустите снова.

## Сборка в exe

```cmd
build.bat
```

Готовый файл появится в `dist\MaxNotifier.exe` вместе с `config.ini`.
Перенесите `MaxNotifier.exe` в любую папку и запустите — рядом автоматически
создадутся `config.ini` и `log.txt`.

## Конфигурация (config.ini)

```ini
[MAX]
; Имя исполняемого файла десктоп-клиента MAX (например, Max.exe)
PROCESS_NAME=max.exe

; Режим отладки: логирует все новые окна (для поиска нужного)
; true или false
DEBUG=false

[SMTP]
; SMTP-сервер для отправки email
SMTP_HOST=
; Порт (465 для SSL, 587 для STARTTLS)
SMTP_PORT=465
; Логин (email отправителя)
SMTP_LOGIN=
; Пароль или app-пароль для SMTP
SMTP_PASSWORD=
; Адрес получателя
EMAIL_TO=
; Интервал между письмами в секундах (защита от спама)
COOLDOWN_SECONDS=60
```

Все параметры обязательны (кроме `DEBUG`). Если хотя бы один не заполнен,
программа выведет понятную ошибку и завершит работу.

## Режим отладки

Если уведомления не приходят или приходят ложные срабатывания, включите
`DEBUG=true` в `config.ini`. В этом режиме программа будет логировать
**все** события окон от процесса MAX (тип события, заголовок, класс, hwnd),
что поможет понять, какие окна создаются и при необходимости уточнить
фильтрацию.

## Структура проекта

| Файл              | Назначение                                              |
|-------------------|---------------------------------------------------------|
| `app.py`          | Точка входа, главный цикл                               |

## Логирование

Все события записываются в `log.txt` рядом с исполняемым файлом.
Формат записей:

```
2026-07-27 14:30:00 [INFO] === MaxNotifier запущен ===
2026-07-27 14:30:01 [INFO] Поиск главного окна MAX...
2026-07-27 14:30:02 [INFO] Главное окно MAX найдено (hwnd=12345, pid=6789)
2026-07-27 14:30:02 [INFO] Мониторинг окон уведомлений MAX запущен
2026-07-27 14:35:10 [INFO] Обнаружено окно уведомления MAX (hwnd=54321, class='...')
2026-07-27 14:35:11 [INFO] Письмо отправлено на user@example.com
```

## Автоматическое переподключение

- **MAX закрыт:** программа ждёт, пока MAX снова запустится, затем
  автоматически возобновляет мониторинг
- **SMTP:** при сбоях отправки письмо пересылается с задержкой от 5 до 60
  секунд до успешной доставки

## Технические детали

- **Python 3.11+**, type hints, PEP 8
- Только стандартная библиотека (`ctypes`, `smtplib`, `ssl`, `configparser`,
  `logging`, `email`)
- Без Docker, баз данных, GUI и лишних зависимостей
- Собранный exe работает без установленного Python
- `config.ini` и `log.txt` создаются рядом с exe (поддержка PyInstaller `frozen`)
- Работает только на Windows (используется Win32 API)
